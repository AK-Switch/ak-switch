## akswitch config list

List runtime-configurable parameters

### Synopsis

Display all runtime-configurable parameters and their current values.

	If a provider name is given, shows parameters for that provider only.
	Use --all to show parameters for all providers.
	Otherwise, shows the first (or only) provider.

```
akswitch config list [provider] [flags]
```

### Options

```
      --all    Show all providers
  -h, --help   help for list
```

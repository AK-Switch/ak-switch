## akswitch provider info

Show detailed information about a provider

### Synopsis

Display detailed configuration and status for a single provider.

Combines config settings, key summary, and runtime status (when server is running)
in one output.

Example:
  akswitch provider info nvidia
  akswitch provider info sensenova

```
akswitch provider info <name> [flags]
```

### Options

```
  -h, --help   help for info
```

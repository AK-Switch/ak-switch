## akswitch log-level

Show or set the log level

### Synopsis

Display the current log level, or set it to a new value.

Valid levels: debug, info, warn, error

Examples:
  akswitch log-level       # show current level
  akswitch log-level debug # set level to debug

```
akswitch log-level [level] [flags]
```

### Options

```
  -h, --help   help for log-level
```

### Task 3.2: ForEach 快照迭代

**Files:**
- Modify: `internal/server/provider_manager.go:74-81`

**Interfaces:**
- Produces: `ForEach(fn func(name string, ps *ProviderState))` — 签名不变，内部改为快照迭代

**Step 1: 修改 ForEach 实现**

Edit `provider_manager.go:74-81`:
```go
// ForEach iterates over all providers.
func (pm *ProviderManager) ForEach(fn func(name string, ps *ProviderState)) {
    pm.mu.RLock()
    defer pm.mu.RUnlock()
    for name, ps := range pm.providers {
        fn(name, ps)
    }
}
```
→
```go
// ForEach iterates over a snapshot of all providers.
// The snapshot is copied under the read lock, then the callback
// executes without holding the lock to avoid deadlocks.
func (pm *ProviderManager) ForEach(fn func(name string, ps *ProviderState)) {
    pm.mu.RLock()
    providers := make(map[string]*ProviderState, len(pm.providers))
    for name, ps := range pm.providers {
        providers[name] = ps
    }
    pm.mu.RUnlock()

    for name, ps := range providers {
        fn(name, ps)
    }
}
```

### Task 3.3: buildTargetURL URL 解析修复

**Files:**
- Modify: `internal/server/proxy_handler.go:51-60`
- Test: `internal/server/proxy_executor_test.go:286-293`

**Interfaces:**
- Produces: `buildTargetURL(cfg *config.Config, path, rawQuery string) string` — 签名不变，内部用 `url.Parse`

**Step 1: 添加 net/url import**

Edit `proxy_handler.go` import block, add `"net/url"` (alphabetical order).

**Step 2: 修改 buildTargetURL**

Edit `proxy_handler.go:51-60`:
```go
// buildTargetURL constructs the upstream URL.
func buildTargetURL(cfg *config.Config, path, rawQuery string) string {
    if strings.HasSuffix(cfg.TargetBase, "/v1") && strings.HasPrefix(path, "/v1") {
        path = path[3:]
    }
    if rawQuery != "" {
        path += "?" + rawQuery
    }
    return cfg.TargetBase + path
}
```
→
```go
// buildTargetURL constructs the upstream URL.
func buildTargetURL(cfg *config.Config, path, rawQuery string) string {
    base, _ := url.Parse(cfg.TargetBase)
    if strings.HasSuffix(base.Path, "/v1") && strings.HasPrefix(path, "/v1") {
        path = path[len("/v1"):]
    }
    base.Path = strings.TrimRight(base.Path, "/") + path
    if rawQuery != "" {
        base.RawQuery = rawQuery
    }
    return base.String()
}
```

关键变更:
- `url.Parse(cfg.TargetBase)` 只解析 URL 结构，`base.Path` 只包含路径部分
- `path[3:]` → `path[len("/v1"):]`，语义明确
- `base.Path = ...` + `base.String()` 正确拼接 URL

**Step 3: 验证现有测试**

现有测试 `TestBuildTargetURL_BasicPath`：
- `TargetBase: "https://api.example.com/v1"`, path: `/test/v1/chat`
- 期望: `https://api.example.com/v1/test/v1/chat`
- `url.Parse` 后 `base.Path = "/v1"`, 不满足 `HasPrefix(path, "/v1")`，不截断
- 拼接: `/v1` + `/test/v1/chat` = `/v1/test/v1/chat` → PASS

Run: `go test -tags=unit -count=1 -run TestBuildTargetURL ./internal/server/`
Expected: PASS

**Step 4: 提交**
